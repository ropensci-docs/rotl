# Methods for Taxonomy

Methods for dealing with objects containing taxonomic information
(Taxonomy, TNRS endpoints)

## Usage

``` r
tax_rank(tax, ...)

ott_id(tax, ...)

synonyms(tax, ...)

tax_sources(tax, ...)

is_suppressed(tax, ...)

unique_name(tax, ...)

tax_name(tax, ...)
```

## Arguments

- tax:

  an object returned by
  [`taxonomy_taxon_info`](https://docs.ropensci.org/rotl/reference/taxonomy_taxon_info.md),
  [`taxonomy_mrca`](https://docs.ropensci.org/rotl/reference/taxonomy_mrca.md),
  or
  [`tnrs_match_names`](https://docs.ropensci.org/rotl/reference/tnrs_match_names.md)

- ...:

  additional arguments (see
  [`tnrs_match_names`](https://docs.ropensci.org/rotl/reference/tnrs_match_names.md))

## Details

This is the page for the generic methods. See the help pages for
[`taxonomy_taxon_info`](https://docs.ropensci.org/rotl/reference/taxonomy_taxon_info.md),
[`taxonomy_mrca`](https://docs.ropensci.org/rotl/reference/taxonomy_mrca.md),
and
[`tnrs_match_names`](https://docs.ropensci.org/rotl/reference/tnrs_match_names.md)
for more information.
